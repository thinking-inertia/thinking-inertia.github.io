01 / MOTIVATION

A no-thinking switch does not guarantee an answer-only response

Before defining no-thinking, we ask a simpler question: when a model is told to return only the answer, is the visible pre-answer field actually empty? Figure 1 shows that the requested mode and the emitted response can diverge.

The key distinction

A no-thinking control specifies the request—not the response. Even with a clear answer-only instruction, a model may expose question-relevant text before a correct final answer; under native no-thinking, this exposure changes systematically with the answer space.

01 / INSTRUCTION FAILURE

The instruction–response gap

Both models return the correct option, yet expose question-relevant text before it. Correctness therefore does not certify answer-only compliance.

02 / ANSWER-SPACE GRADIENT

The answer space changes compliance

Under native no-thinking, Boolean outputs stay closest to the answer-only boundary, MCQ is intermediate, and Open-ended outputs retain the most visible pre-answer text.

These observations motivate the response-level object used below: separate the pre-answer text T from the final answer A, then distinguish empty output, relevant context, and explicit inference.

ABSTRACT / TWO QUESTIONS

What does ``no-thinking'' look like in an emitted response?

Large Language Models (LLMs) increasingly ship with explicit ``thinking modes'', yet their counterpart, ``no-think'', has received far less attention. We study no-thinking as a response-level behavior along two complementary axes.

A / MEASUREMENT

How should no-thinking be measured?

Prior work often relies on a disabled thinking mode or the absence of a long trace. These proxies are unreliable: disabled modes can still emit extended reasoning, while long traces can contain filler rather than genuine inference. We normalize each response into visible pre-answer text and a final answer, then evaluate the pre-answer field at three progressively specific levels.

ETR strict answer-only complianceQRel. instruction-aware question relevanceEIR visible explicit inference

Together, the levels separate empty output, relevant but non-inferential text, and explicit inference. Human studies validate the measurement hierarchy.

B / BEHAVIOR

How does no-thinking vary?

We evaluate six prompting interventions on six widely used LLMs, spanning open-source and commercial models, across Boolean, multiple-choice, and open-ended questions. Explicit no-think controls cannot reliably eliminate visible explicit inference.

Thinking Inertiavisible explicit inference persists under strict no-thinking controlsBool < MCQ < Openthe response-level signal grows as the answer space opensCompliance ↔ accuracyopen-ended tasks expose the no-thinking–performance trade-off

Rewriting the same questions across answer spaces further shows that supplying candidate answers makes answer-only responses easier to produce.

The paper in one sentence

Stopping visible explicit inference cannot be assumed from a model setting or instruction alone; no-thinking deserves systematic evaluation alongside reasoning ability itself.

02 / DIAGNOSIS

Why surface proxies fail

A disabled mode, a missing ``<think>'' tag, or a short generation describes the interface. None of them identifies what the response actually reveals.

The measurement gap

Surface proxies conflate instruction control, output format, and length with the behavioral object we want to study: visible pre-answer content.

The observable target

We evaluate T directly and evaluate answer correctness on A separately. This keeps visible reasoning claims at the response level, without making a claim about latent cognition.

04 / THREE-LEVEL MEASUREMENT

From answer-only format to explicit inference

Each level answers a narrower question about the same visible pre-answer field. Together they prevent relevance from being mistaken for reasoning.

01

ETR

Empty-Thinking Ratio

Is T empty? This is the strict answer-only boundary.

empty(T) / all outputs
02

QRel.

Question–Pre-answer Relevance

Does T help answer Q? It is an instruction-aware relevance signal, not a reasoning detector.

relevance(Q, T)
03

EIR

Explicit Inference Rate

Does T contain a visible inferential step? A blinded judge applies the five-way rubric.

explicit inference / all outputs

The hierarchy is deliberately progressive: ETR establishes compliance, QRel. describes the relevance of residual text, and EIR separates relevant statements from deduction, computation, comparison, elimination, rule application, evidence-to-conclusion, or causality. Empty T is no visible inference by definition.

05 / EXPERIMENTAL STORY

What the experiments reveal

We use Thinking Inertia for a specific response-level behavior, then test whether it survives changes in answer space and no-thinking control.

Working definition

Thinking Inertia

the persistence of visible, question-conditioned pre-answer text that contains explicit inference after the model has been told not to think. It is a claim about the emitted response—not latent cognition—and is measured through EIR, with ETR and QRel. providing complementary context.

No-thinking instruction→Visible pre-answer text T→Explicit inference
01Answer space

More open interfaces preserve more visible inference

Across native and stricter no-thinking settings, the response-level signal follows a staircase: Boolean tasks are closest to answer-only, multiple-choice tasks are intermediate, and open-ended tasks retain the most explicit pre-answer work.

Bool<MCQ<Openvisible inference increases with answer freedom
02Mode effect

Stricter controls reduce the behavior, but do not erase it

Within every answer space, stronger no-thinking control yields lower explicit inference than the native no-thinking setting. The remaining Open-ended signal is the response-level signature of thinking inertia.

03 / ACCURACY

Compliance and capability are separate axes

A cleaner answer-only format does not automatically mean a more capable answer. Accuracy on A is read alongside ETR, QRel., and EIR.

04 / CONTROL

Matched rewrites isolate the interface

When the same question is rewritten as Boolean, multiple-choice, or open-ended, short targets alone do not explain the pattern; matched lengths can still differ sharply in relevance.

06 / VALIDATION

Checks that keep the interpretation narrow

The evidence is layered so that no single proxy has to carry the reasoning claim on its own.

Q
Relevance robustness

Alternative encoders preserve the relevance ordering, while the instruction-aware QRel. signal remains explicitly separated from reasoning.

J
Judge robustness

Claude Opus 4.8 independently reproduces the Level 3 visible-inference pattern across models, modes, and answer spaces.

H
Human validation

Five blinded annotators review a proportion-matched 600-output sample using the same relevance and reasoning rubric.

Reading guide

ETR marks the answer-only boundary; QRel. measures question-relevant residual text; EIR identifies visible explicit inference. The claim stays at the level of observable response behavior, not latent cognition.
